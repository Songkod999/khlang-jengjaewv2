# คลังเจ๋งแจ๋ว — แอปบันทึกรายรับ/รายจ่าย

ไฟล์ในชุดนี้:
- index.html — ตัวเว็บแอป
- manifest.json — ทำให้เว็บติดตั้งเป็นแอป (PWA)
- sw.js — ทำงานแบบ cache/offline พื้นฐาน
- icon-192.png / icon-512.png — โลโก้ที่ผู้ใช้ส่งมา

## ใช้บน GitHub Pages
1. สร้าง GitHub Repository
2. อัปโหลดไฟล์ทั้งหมดไว้ในโฟลเดอร์เดียวกัน
3. ไปที่ Settings > Pages
4. Source = Deploy from a branch
5. Branch = main และโฟลเดอร์ = / (root)
6. เปิดลิงก์ GitHub Pages ของคุณ
7. ใน Chrome/Edge เลือก "ติดตั้งแอป" หรือ "Add to Home screen"

## ฟังก์ชันที่เพิ่ม
- โปรไฟล์ผู้ใช้: ชื่อ, ตำแหน่ง, ชื่อร้าน และรูปโปรไฟล์
- ใช้โลโก้ “คลังเจ๋งแจ๋ว” เป็นไอคอนของเว็บ/แอป
- รายรับ/รายจ่าย/สินค้า/รายงาน
- เก็บข้อมูลใน LocalStorage ของเบราว์เซอร์
- รองรับมือถือและเดสก์ท็อป
